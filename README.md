# Heli - 赫力

**Heli (赫力): 你的始终在线 AI Agent**

文件访问、多步任务执行、24/7 自动化、远程控制。

[English](./README.md) | 中文

## 关于

赫力（Heli）取自 Helios（希腊太阳神）的前缀，意为光、全局与不息。赫力代表一个始终在线、文件可达、任务可执、远程可控的 AI Agent / 自动化底座。

## 特性

- **文件操作** - 让 AI 直接操作你的文件
- **多步任务** - 自主推进复杂任务，关键操作需你批准
- **远程控制** - 通过 Telegram / Lark / DingTalk / WeChat / WeCom 触发
- **定时自动化** - Cron 调度，24/7 无人值守
- **多 Agent 支持** - 同时运行 Claude Code、Codex、Qwen Code 等 20+ Agent

## 技术栈

- **Tauri 2.0** - 跨平台桌面框架
- **TypeScript** - 类型安全的前后端开发
- **Vite** - 快速的开发构建工具

## 开始使用

```bash
# 克隆仓库
git clone https://github.com/Helios-Online/helios-desktop.git

# 安装依赖
cd helios-desktop
npm install

# 开发模式
npm run dev

# 构建
npm run build
```
